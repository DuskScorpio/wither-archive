## Versions
1.21+. Compatibility unknown for lower versions.
Item version: can break 27 blocks per wither every 20gt.
XP version: can break 18 blocks per wither every 20gt.
## Rates
- collection rate: 100% for item, 99.975% for xp orb
## Features
- Pressure-plate-based unload detector.
- When the chicken is accidentally exposed, the black skulls from the main head will still be blocked.
## Considerations
- The schematics may not work in 1.21.3+. Check if the boat is pasted.
- When you rotate the schematics, the direction of the boat may get wrong.
- These are not issues with the design themselves.
- Reload immediately after pasting.
## Notes
- Each design was tested for 10k+ hours and 10M+ reloads.
- Allays can also be used instead of chickens. In that case, the raft should be placed 4 pixels higher.
